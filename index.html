Sauvegarde & import

Vos données restent sur cet appareil : sauvegardez-les régulièrement.

Les données sont enregistrées dans le navigateur de cet appareil. Effacer les données du navigateur supprime les dossiers et les photos : téléchargez une « Sauvegarde complète » régulièrement (et avant de changer de téléphone).

Exporter / importer

La sauvegarde complète (.json) contient tous les baux, états des lieux et photos. Le tableau (.csv) s’ouvre dans Excel : idéal pour saisir plusieurs anciens baux d’un coup.

Dossiers enregistrés sur ce téléphone

Le dossier est enregistré automatiquement dans ce navigateur. Pour le conserver ou le reprendre sur un autre appareil (par exemple pour faire la sortie), sauvegardez-le en fichier puis rechargez-le ici. Le PDF, lui, ne peut pas être rechargé.

Affichage

L’appli s’adapte automatiquement à l’appareil. Vous pouvez aussi choisir un format.

Installer l’appli

Ajoutez l’appli à l’écran d’accueil pour l’ouvrir comme une application.

Des éléments sont à compléter
